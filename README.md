# La Fonda Antioqueña: website design preview

Live preview: https://aathii.github.io/la-fonda-demo/

A design preview built with the Master Blueprint, shared for review. It is not the restaurant's official website and is kept out of search engines. Restaurant photos are used with the owner's consent; menu prices and hours come from the restaurant's DoorDash and Postmates listings (September 2026).

Static site: `index.html`, `css/`, `js/`, `fonts/`, `media/`. The source project, film build scripts and QA records live in the Master Blueprint workspace.
